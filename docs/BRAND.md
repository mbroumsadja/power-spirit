# power spirit — Guide de marque

## Essence
**Mission** : permettre à un groupe d'échanger vite, sans compte, sans trace.
**Personnalité** : joueuse, rapide, rassurante, discrète. **Promesse** : *Discute. Partage. Disparais.*
**Nom** : toujours en minuscules, en deux mots : `power spirit`. Jamais « PowerSpirit » ni « Power Spirit » dans un titre ou un logo.

## Logo
Logomark = fantôme violet (l'esprit), éclair jaune (power), contour d'encre et ombre dure. Wordmark = *Bricolage Grotesque ExtraBold*, tracé en chemins (aucune dépendance de police).
| Fichier (`public/brand/`) | Usage |
|---|---|
| `logo-horizontal.svg` / `-dark.svg` | en-têtes, documents (fond clair / sombre) |
| `logo-stacked.svg` / `-dark.svg` | écran d'accueil, affiches |
| `logomark.svg`, `logomark-flat.svg` | avatar, favicon agrandi, réseaux ; *flat* = sans ombre pour très petits formats |
| `logo-mono-ink.svg`, `logo-mono-white.svg`, `logomark-mono-*.svg` | impression 1 couleur, tampons, fonds photo |
| `icon.svg`, `icon-plate.svg`, `icon-maskable.svg`, `icon-192/512.png`, `apple-icon.png`, `favicon.ico` | favicon, PWA, iOS, Android |
| `mascot-sleep.svg`, `mascot-wow.svg` | états vides, succès |
| `og-image.png` | aperçu de partage (1200×630) |

**Zone de protection** : une demi-largeur du fantôme tout autour. **Tailles minimales** : logo horizontal 100 px de large ; logomark 20 px (en dessous : `logomark-flat`).
**Interdits** : étirer, pivoter, changer les couleurs, retirer l'éclair, ajouter un effet (flou, dégradé, lueur), poser sur un fond de contraste < 3:1.

## Voix & ton (français)
Tutoiement, phrases courtes, verbes d'action, zéro jargon. Humour léger, jamais au détriment de la clarté.
| Contexte | Oui | Non |
|---|---|---|
| Accueil | « Ton pseudo » · « Entrer dans le salon » | « Veuillez renseigner votre identifiant » |
| Vide | « C'est calme ici. » | « Aucun message. » |
| Erreur | « Tu as été exclu. Réessaie dans 30 s. » | « Erreur 403 » |
| Départ | « Amina a quitté le salon » | « Utilisateur déconnecté » |
Message-clé à répéter : *rien n'est conservé*. Une fois par écran d'entrée suffit.

## Applications
Favicon et icône d'app (fantôme sur pastille jaune) · carte de partage `og-image.png` · en-tête violet de l'app · autocollants (mascotte sur fond jaune, contour blanc 3 mm) · bannière GitHub : logo horizontal sur ciel `#DFF3FF`.
